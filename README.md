# Sobre mim

Sou desenvolvedor Full Stack focado na criação de aplicações web, SaaS, sistemas de gestão, dashboards e soluções para negócios.

Trabalho principalmente com React, TypeScript, Node.js, PostgreSQL e Supabase, mas também exploro desenvolvimento desktop, mobile, animações e diferentes arquiteturas de aplicações.

Meu objetivo é transformar necessidades reais em software funcional, bem estruturado e com boa experiência de usuário.
